What's New (DFendX)

This page summarizes new features available in DFendX.

» Support for DOSBox-X and DOSBox Staging

DFendX has first-level support for these two modern DOSBox forks.

You can add them as installations as normal, and DFendX will recognize them as valid DOSBox installations.

Furthermore, certain configuration values in the generated dosbox.conf will be different depending on which kind of DOSBox is selected for the profile.

» Support for eXoDOS

DFendX has direct support for eXoDOS as a source of game metadata, media resources (screenshots, sounds, manuals etc.) and as a way of directly adding games.

You can configure the eXoDOS location under the "External programs" area in the program options.

After you select a valid eXoDOS location, you must click the "Read games..." button to build the databases that index eXoDOS content. You can then view the list of available games with the "List games..." button.

If your eXoDOS installation is successfully indexed, you will have various options available:

  • In the Program information page of the profile editor, when you click on "Download game information", you will have eXoDOS as a source to pull metadata from.
  • In the media tabs of the main profile list view, you will see additional media from eXoDOS, as well as a new Docs tab that contains manuals and other documents from eXoDOS.
  • When adding games to DFendX you will see an extra option "Add from eXoDOS". This allows you to create a profile pointing at the location where eXoDOS unpacks game archives. Note: the setup program of a profile created from eXoDOS will point at eXoDOS's own setup.bat file — this is the installer that unpacks the game and gives you various options to select. Note that few of them will affect the DFendX profile; you are free to set your own options through DFendX as normal. However, until you run the setup, the profile's game executable will point at a non-existent location.

» Pixel shader detection

For DOSBox-X and Staging, DFendX will look in standard locations for pixel shader files that come with those distributions, and add them to the Pixel shader combo box that is now permanently enabled in the Graphics page of the profile editor.

Note you should always select "openglnb" as the Render option, and "No scaling" as the Scale option when using pixel shaders.

DFendX will automatically set the correct pixel shader option in dosbox.conf for your selected DOSBox installation.

» Autoplay game soundtrack

In the main user interface, you will note an "Autoplay" toggle switch. Turning that on will enable background music to play (through DFendX itself), based on a file identified as a soundtrack through its filename. This applies to soundtracks from eXoDOS as well as any files the user places in the game's capture folder with "soundtrack" in the filename.
