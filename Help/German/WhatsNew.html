Was ist neu (DFendX)

Diese Seite fasst neue Funktionen in DFendX zusammen.

» Unterstützung für DOSBox-X und DOSBox Staging

DFendX unterstützt diese beiden modernen DOSBox-Ableger auf erster Ebene.

Sie können sie wie gewohnt als Installationen hinzufügen; DFendX erkennt sie als gültige DOSBox-Installationen.

Außerdem unterscheiden sich bestimmte Werte in der erzeugten dosbox.conf je nachdem, welche DOSBox-Variante für das Profil gewählt ist.

» Unterstützung für eXoDOS

DFendX unterstützt eXoDOS direkt als Quelle für Spiele-Metadaten, Medien (Screenshots, Sounds, Handbücher usw.) und zum direkten Hinzufügen von Spielen.

Den eXoDOS-Pfad konfigurieren Sie im Bereich "Externe Programme" der Programmeinstellungen.

Nachdem Sie einen gültigen eXoDOS-Pfad gewählt haben, müssen Sie auf "Spiele einlesen..." klicken, um die Index-Datenbanken aufzubauen. Die Liste der verfügbaren Spiele können Sie anschließend mit "Spiele auflisten..." anzeigen.

Ist eXoDOS erfolgreich indiziert, stehen unter anderem folgende Möglichkeiten zur Verfügung:

  • Auf der Seite Programminformationen im Profileditor können Sie beim Laden von Spielinformationen eXoDOS als Quelle wählen.
  • In den Medien-Registerkarten der Hauptansicht erscheinen zusätzliche eXoDOS-Medien sowie ein neues Register "Dokumente" mit Handbüchern und anderen Dateien aus eXoDOS.
  • Beim Hinzufügen von Spielen gibt es die Option "Aus eXoDOS hinzufügen". Damit erstellen Sie ein Profil auf dem Ordner, in dem eXoDOS Spielarchive entpackt. Hinweis: Das Setup-Programm eines so erzeugten Profils zeigt auf die eXoDOS-eigene setup.bat — den Installer, der das Spiel entpackt und diverse Optionen anbietet. Nur wenige davon wirken sich auf das DFendX-Profil aus; Sie können die Einstellungen weiterhin normal in DFendX vornehmen. Solange Setup nicht gelaufen ist, zeigt die Spiele-EXE des Profils auf einen noch nicht vorhandenen Pfad.

» Pixel-Shader-Erkennung

Für DOSBox-X und Staging sucht DFendX an den üblichen Orten nach Pixel-Shader-Dateien dieser Distributionen und trägt sie in die nun dauerhaft freigegebene Pixel-Shader-Liste auf der Seite Grafikkarte des Profileditors ein.

Bei Verwendung von Pixel-Shadern sollten Sie als Renderer "openglnb" und als Skalierung "Keine Skalierung" wählen.

DFendX setzt den passenden Pixel-Shader-Eintrag in der dosbox.conf automatisch für die gewählte DOSBox-Installation.

» Autoplay für Spiele-Soundtracks

In der Hauptoberfläche gibt es den Schalter "Autoplay". Ist er aktiv, spielt DFendX Hintergrundmusik ab, basierend auf einer Datei, die über den Dateinamen als Soundtrack erkannt wird. Das gilt für eXoDOS-Soundtracks und für Dateien im Capture-Ordner des Spiels, deren Name "soundtrack" enthält.
